Design System MeghDrishti
1 Visual Theme and Atmosphere
A professional analyst workspace with a white canvas, disciplined neutral typography and one muted teal accent. Density 6 of 10, variance 4, motion 3. Prioritize dependency evidence and investment figures over ornamental graphics. Use a two-to-one graph/detail workspace; concise, left-aligned headings. No workspace hero photography or overlapping decorative content. Welcome uses a left-aligned explanation and a small dependency schematic rather than an advertising hero.
2 Color Palette and Roles
Canvas White #FAFAFA is the primary background. Pure Surface #FFFFFF holds panels. Charcoal Ink #18181B is primary text; Muted Zinc #52525B is secondary text; Whisper Border #E4E4E7 divides sections. Teal Signal #397D76 is the single chromatic accent for primary actions, selection, focus and affected-path outlines. Pale teal surfaces use the same accent at reduced opacity. Use neutral fills, icons, textual badges and border patterns for synthetic/unknown/failed states; no reliance on colour alone. No pure black UI, purple, neon or gradients. Verify contrast for actual foreground/background pairs.
3 Typography Rules
Use Geist Sans for headings/body and Geist Mono for financial values, IDs and time metadata, with accessible sans/mono fallbacks. Local font assets preferred. Body 16px, metadata 14px minimum, page title clamp(24px, 2vw, 32px); headings 18–22px. Weights 400, 500, 600. Text leading 1.5; explanatory paragraphs maximum 65 characters per line. Tabular numerals and INR formats consistent across pages. No serif, oversized dashboard headings or decorative all-caps paragraphs.
4 Component Stylings
Buttons: 8px radius, 44px minimum target, flat accent primary, neutral outline secondary. Active feedback uses transform only. Labels above fields, helper text and specific validation below; never placeholder-only fields. Panels have 12px radius and 1px borders; shadows only for drawers/popovers. Avoid rows of three equal feature cards. Metrics use a compact two-column grid or horizontal divided strip rather than large marketing cards. Tables align text left and monetary values right; row selection is keyboard accessible. Badge labels Synthetic, Dataset reported, Sourced, Assumed, Unknown and Stale use neutral distinctions and icons. Every metric includes scope and units. Node types use compact icons/text roles; selected path uses teal outline plus readable path list.
Loaders: skeletons at actual panel dimensions, brief subtle shimmer only while loading. Empty states explain the next action. Errors are inline and persistent until resolved. No fake live counters, confidence scores or speculative placeholders presented as real facts.
5 Layout Principles
Desktop reference 1440px, content maximum 1440px, sidebar 240px, header 72px, main padding 24–32px, 8px spacing scale. Primary workspace is graph/map on left with event/evidence drawer on right. Grid-first layout with explicit min-width handling. Financial charts have intentional axes and units, not decorative spark lines. All pages reuse one shell. Avoid text collisions in graphs through deterministic layout and fit-to-view; don't place content with overlapping absolute-positioned blocks.
Below 768px collapse panels into one column; sidebar becomes a drawer; tables become stacked summaries or contained scrolling regions with labels. No page-wide horizontal overflow. Touch controls minimum 44px. Use min-height 100dvh when full-height panels are needed, not fixed h-screen.
6 Motion and Interaction
Transitions 120–180ms using transform/opacity. Optional spring feedback stiffness 100 damping 20. Pending skeleton may loop; inactive/static analytics must not pulse or imply live data. Stagger only initial short list appearance when it improves orientation. Graph layout animation respects reduced motion. Do not animate positions with top/left/width/height or make permanent kinetic charts. prefers-reduced-motion removes shimmer and layout animation.
7 Anti Patterns
No emojis, Inter, serif dashboard fonts, pure black UI, neon glows, oversaturated accents, gradient headlines, custom cursors, overlapping text, marketing card grids, fake round accuracy statistics, generic filler names or AI slogans. Use specified fictional demo businesses consistently. No stock photos, external placeholder-photo dependencies, fake connected badges, invented supplier/source links, fabricated forecasts, or stock-loss language. No icons standing alone as an explanation of risk. No disconnected page designs with different palettes/navigation. No mandatory event creation before automatic screening can show findings.
8 Screen and Content Contract
Follow P01–P11 in PRD.md. Persist a visible Demo simulation banner in every synthetic-data workspace. Preserve coverage/unknown states and labels. Use reference fixture numbers from PRD section 9 only. Do not invent other metrics. The apparent automatic event is labelled a stored synthetic event. Sourced-mode variants show supported source status and timestamps. Stitch provides layouts; implementation replaces graph/chart/map placeholders with React Flow, Recharts and Leaflet without restyling the application.
